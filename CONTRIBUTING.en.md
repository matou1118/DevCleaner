# Contributing (English)

Thanks for taking the time. The project is small and the rules are few, but there is **one hard requirement**.

## Hard requirement: changing a cleanup criterion requires a test

This isn't bureaucracy. This tool deletes things on your machine, and a wrong criterion costs you
"deleted something in use and can't get it back".

So:

- Change any scanner's criteria → add a case in `test_app.py`; **make it fail first, then make it pass**
- Fix a false positive → add a case that pins it down (see `t_no_false_orphan`)
- Loosen any safety rail → explain in the same PR why you believe it's safe

`python test_app.py` must be fully green. CI runs it on Python 3.10 through 3.13.

## Setup

```bash
pip install -r requirements.txt
python test_app.py        # 35 self-checks, ~50s
python gui.py             # try it locally
build.bat                 # package to dist\DevCleaner.exe
```

If you're only touching the UI or docs you can skip PySide6, but one self-check builds the window
headless, so installing it saves friction.

## Style

Match the surrounding code. Concretely:

- **Standard library first.** The engine uses only `psutil` + `PyYAML`; everything else is stdlib. Think before adding a tool
- **No new dependencies** unless one replaces a large chunk of hand-written code. Ask in an issue first
- **Don't refactor what you weren't asked to touch.** Separate PR
- Chinese is fine for UI strings, but `build.bat` must stay pure ASCII — cmd reads `.bat` in the OEM codepage, and CJK plus `&` gets mis-parsed into a command that doesn't exist
- Don't edit sources with PowerShell's `Get-Content`/`Set-Content`. They read UTF-8 as ANSI and mangle non-ASCII

## Before you push

```bash
python test_app.py
git status          # don't commit build/ dist/ __pycache__/
```

Never commit `.reg` backups or scan output. `settings.yaml` *is* committed (it's the default config),
but put your machine-specific paths in `settings.local.yaml`.

## Adding a scanner

```python
class MyScanner(Scanner):
    category, icon = "My category", "\U0001f9f0"

    def scan(self) -> List[Item]:
        return [mk(self.category, Path("C:/some/cache"), "name", "safe",
                   note="why this is safe to delete")]
```

Then append it to `SCANNERS`. The UI grows a collapsible group automatically — **no UI code to touch**.

Two requirements:

- Be honest about `risk`. If you're unsure use `caution`; the user then won't get it pre-checked
- If the items are 0 bytes (registry, empty files), set `Item.unit = "count"` — the UI shows an entry
  count rather than pretending with bytes

## Changing the palette

Colours live in `_PALETTES` in `app.py`; the original design file is `docs/palette-directions.html`.

Secondary/tertiary text, borders, and text-on-accent are **derived**, not hand-copied — change a
primary colour and they follow.

If a palette fails WCAG AA, `t_theme_contrast` will stop you. When text on accent doesn't have enough
contrast, it automatically picks whichever of white / background scores higher.

## Changing the UI

One file, `gui.py`; the QSS is generated by `build_qss(theme)`.

There's a trap documented in the code: colour the selected row with `QPalette`, **not**
`setObjectName` + `unpolish`/`polish`. The latter makes Qt re-resolve the entire stylesheet —
auto-selecting 27 rows is 27 full re-resolutions back to back, the main thread locks up, and you
get a full-window flash. `t_no_repolish_on_check` guards it.

## Translations

`README.en.md` / `CONTRIBUTING.en.md` / `SECURITY.en.md` mirror the Chinese versions. If you change
one, update the other. UI i18n isn't done yet (see the roadmap).

## Not accepted

- Scanning and deleting directories that can't be determined programmatically
- Walking registry areas like `HKCR\CLSID`
- Trading readability for fewer lines
- Features that require administrator rights (except keys under `HKLM`, which already report
  "insufficient permission" cleanly when unelevated)
